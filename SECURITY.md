# Security policy

## Supported versions

Security fixes are applied to the latest published version of
`@linwooddev/style`. Upgrade to the newest release before reporting an issue
that may already have been fixed.

## Report a vulnerability

Please use GitHub's private vulnerability reporting feature for this
repository. Include a clear description, reproduction steps, affected versions,
and the potential impact when possible.

Do not disclose the issue publicly until the maintainers have investigated it
and coordinated a fix.
